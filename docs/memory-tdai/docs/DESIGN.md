# memory-tdai Dashboard · Design Specification

> 视觉规范 · 遵循 Apple Human Interface Guidelines
> 最后更新：2026-06-24 · 维护者：Ray

---

## 🎯 设计目标

**"系统健康仪表盘"** — 像 Apple Health 或 Xcode Organizer 那样，
用清晰的数字 + 颜色语义，让插件状态一目了然。

**关键词：** 健康状态 · 分层清晰 · 数据密度适中 · 告警优先

## 🏥 健康状态卡片（Stat Card）

### 结构

```
┌─────────────────────────────────────┐
│  [图标]  指标名称                    │
│                                     │
│  98.9%         🟢                   │
│  [大数字]    [状态徽章]              │
│                                     │
│  16826 / 16928 条                   │
│  [说明文字]                          │
└─────────────────────────────────────┘
```

### 颜色语义（全局统一）

| 颜色 | Token | 含义 |
|------|-------|------|
| 绿色 | `--accent-green` | 健康 / 正常 / 增长 |
| 黄色 | `--accent-orange` | 警告 / 需要关注 |
| 红色 | `--accent-red` | 错误 / 危险 / 超过阈值 |
| 蓝色 | `--accent-blue` | 信息 / 正常状态 |
| 灰色 | `--accent-gray` | 未知 / 无数据 / 未配置 |

### 阈值映射规则

| 指标 | 🟢 绿色 | 🟡 黄色 | 🔴 红色 |
|------|---------|---------|---------|
| L0 向量完整率 | ≥ 99% | 95~99% | < 95% |
| L1 向量完整率 | ≥ 99% | 95~99% | < 95% |
| HTTP 400 次数/24h | 0 | 1~5 | > 5 |
| WAL 大小 | < 5MB | 5~20MB | > 20MB |
| vectors.db 大小 | < 500MB | 500MB~1GB | > 1GB |
| L0 HTTP 400/小时 | < 1 | 1~5 | > 5 |
| Scene block 新鲜度 | ≤ 7 天 | 7~30 天 | > 30 天 |
| Persona 新鲜度 | ≤ 30 天 | 30~90 天 | > 90 天 |
| Cleaner 过期数/天 | > 0 | = 0（连续 3 天）| — |
| API 可用率 | ≥ 99.5% | 95~99.5% | < 95% |

## 🏷️ 告警面板

### 优先级排序

```
critical（红色） → error（红色） → warning（橙色） → info（蓝色） → success（绿色）
```

### 告警项结构

```
🔴 [CRITICAL] L0 向量完整率 94.2%（缺失 982 条）
   当前值: 94.2% | 阈值: ≥ 99% | 持续: 3 天
   根因: MAX_BATCH_SIZE=256 vs API limit=10

🟡 [WARNING] Cleaner 连续 5 天 0 条过期
   retention=90天 可能过长，建议调整为 30 天
```

### 告警响应手册（超链接）

每个告警码可链接到 `MONITORING_GUIDE.md` 中的对应章节。

## 📱 Tab 导航（可选）

若指标过多，可分为 3 个 Tab：

| Tab | 内容 |
|-----|------|
| 概览 | 健康状态卡片 + 告警面板 + 向量完整性 |
| 管线 | L1 extraction + L2 scene blocks + L3 persona |
| 存储 | vectors.db + WAL + JSONL + Backup + Cleaner |

**默认打开 Tab 1（概览）**

---

## 🔄 数据刷新

- **自动刷新**：Dashboard HTML 每 60 秒重新 fetch `data/latest.json`
- **刷新时显示**：顶部导航栏显示"上次更新: HH:MM:SS"
- **刷新失败**：静默重试（最多 3 次），不显示错误提示（数据来自本地 cron）
